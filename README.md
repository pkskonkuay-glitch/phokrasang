# phokrasang — ที่นี่โพธิ์กระสังข์

เว็บชุมชนกวยบ้านโพธิ์กระสังข์ (ข่าว คลิป วิถีกวย คำศัพท์กวย ผลิตภัณฑ์ชุมชน) ใช้ฟรีทั้งหมด โฮสต์บน GitHub Pages

## ไฟล์หลัก
- `index.html` หน้าเว็บ • `vocab.html` คลังคำศัพท์ • `admin.html` หลังบ้านสำหรับแอดมิน • `config.js` ตั้งค่าและชื่อหัวข้อ
- `data/*.json` ไฟล์สำรองข้อมูลที่บอตดึงจาก Google Sheet ทุก 30 นาที (ห้ามแก้เอง) • `data/archive/` คลังย้อนหลัง (เพิ่มอย่างเดียว)
- `s/*.html` หน้าแชร์รายเรื่องสำหรับ LINE/Facebook • `build-share.js` + `.github/workflows` บอตสร้างหน้าแชร์ sitemap และไฟล์สำรอง
- `life.gs`, `vocab.gs` โค้ด Apps Script ของหลังบ้าน (ฐานข้อมูลคือ Google Sheet ไม่ใช่ไฟล์ใน repo)

## ก่อนแก้ข้อมูล
ข้อมูลจริงอยู่ใน Google Sheet การแก้ไฟล์ `data/*.json` ตรง ๆ จะถูกบอตเขียนทับในรอบถัดไป ให้แก้ผ่านหน้า admin หรือชีต แล้วรอบอตดึงใหม่

## หลักการ
เนื้อหาคงอยู่ตลอดไป ไม่มีข่าวหมดอายุ ตรวจย้อนหลังได้ • ดูวิธีกู้ระบบและตารางไฟล์ทั้งหมดใน `RECOVERY.md`

## อัลบั้มภาพ (album.html)
- รูปอยู่ที่ `albums/kathin69/web/` (ไฟล์เต็ม 1600px) และ `thumb/` (ย่อ 480px) ชื่อไฟล์ต้องตรงกัน; รายชื่อรูปของแต่ละช่วงอยู่ใน `photos-<ช่วง>.csv` (3 ช่วง: `1-parade`, `2-baisri`, `3-offering`)
- แก้ภาพเด่น/คำบรรยายที่คอลัมน์ `featured(x)` (ใส่ x) และ `caption` แล้วอัปโหลดทับ ไม่ต้องแก้โค้ด
- เซฟ CSV เป็น "CSV UTF-8 (คั่นด้วยจุลภาค)" และบรรทัดแรกต้องขึ้นต้น `new_name,full_seq,time,...` เป็นหลายช่อง ห้ามให้ทั้งบรรทัดอยู่ในช่องเดียว (หน้าเว็บแกะให้อัตโนมัติ แต่ควรเซฟให้ถูก)
- เพิ่มช่วงใหม่: เพิ่มรายการใน `SECS` ต้นสคริปต์ของ `album.html` + ไฟล์ CSV ของช่วงนั้น
